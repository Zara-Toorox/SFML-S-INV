# Solar Forecast S-INV

**Early BETA** – one Home Assistant integration for many inverters, batteries and meters, with the same entity names, units and signs for every manufacturer.

Supported: Anker Solix (cloud), Fronius, Sungrow, Zendure, Hoymiles (OpenDTU, AhoyDTU, DTU / HMS-W), KOSTAL PLENTICORE G2, SolaX, Huawei SUN2000 and Solakon ONE – all except Anker on the local network and read only.

The device "S-INV Anlage" combines all systems into one set of totals for the energy dashboard.

Please read the Early BETA notes in the README before installing. Several manufacturers are built from their protocol documentation and still wait for feedback from testers.
